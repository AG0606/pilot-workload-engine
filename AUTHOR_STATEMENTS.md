### Data Availability Statement
The code and benchmark artifacts generated during this study are openly accessible in the project repository at `pilot_workload_engine/`. The primary benchmark dataset is available via the Kaggle / NASA "Reducing Commercial Aviation Fatalities" challenge repository. The complete unit test suite and empirical database benchmark suite are reproducible via the commands provided in the repository documentation.

### Ethical Approval & Human Participants
This study utilized pre-existing, de-identified public benchmark flight simulator datasets collected under institutional IRB protocols. No new invasive or non-invasive human testing was conducted directly by the authors.
